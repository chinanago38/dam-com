布引五本松ダムの見学ガイド

最終確認日：2026年11月25日

布引五本松（ぬのびきごほんまつ）ダムは、兵庫県神戸市中央区の生田川にある、神戸の水道のためのダムです。正式には「五本松堰堤（えんてい）」といい、明治33年（1900年）に完成しました。水道専用の重力式コンクリートダムとしては日本で最初のものとされ、「布引水源地水道施設」の一つとして国の重要文化財に指定されています。

完成から120年以上たった今も、神戸市の水道施設として使われている現役のダムです。新幹線の新神戸駅から続くハイキングコースを歩いて行くことができ、途中で名所の「布引の滝」も見られます。

布引五本松ダムの歴史

明治23年（1890年）、神戸ではコレラが流行しました。これを教訓に、安全な水を届ける上水道をつくろうという動きが高まります。明治25年（1892年）にはイギリス人技師のW.K.バルトンが設計を担当し、はじめは土を盛ってつくる「土堰堤」の案でした。

明治26年（1893年）に水道をつくることが決まりましたが、日清戦争のために工事の始まりがおくれました。その間に、技師の佐野藤次郎が設計を見直し、土堰堤からコンクリートの堰堤へと変更しました。建設は、神戸水道事務所の吉村長策と佐野藤次郎を中心に進められました。

工事では、フランスのドコービル社の小さな線路（ナローゲージ）を使い、馬で資材を運びました。工事が終わると、そのレールは手すりの鉄骨や管理橋の材料に再利用されています。

完成後も施設は増やされ、明治40年（1907年）に分水施設、明治41年（1908年）に締切堰堤と放水路のトンネルが加えられました。平成7年（1995年）の阪神・淡路大震災では、大きくくずれることはありませんでしたが、漏水が増えたため、今のダムの設計基準に合わせた補強工事が行われました。工事は、文化財としての価値をそこなわないように進められています。

2006年には、五本松堰堤をはじめ、雌滝取水堰堤、布引水路橋、分水施設、締切堰堤、放水路隧道などが「布引水源地水道施設」として国の重要文化財に指定されました。文化庁の解説では、五本松堰堤は日本の重力式コンクリート造の堰堤の始まりであり、近代の堰堤のお手本を示す構造物として、土木技術の歴史の上で高い価値があるとされています。

ダムのつくりと見どころ

  • 石張りの堤体：コンクリートを固めるときの型枠に使った切石を生かして、表面が石積みで仕上げられています
  • デンティル（歯飾り）：ダムの上部には、歯が並んだような飾り「デンティル」がついています
  • 英文の銘板：頂上の側壁には、吉村長策・佐野藤次郎・浅見忠治の名前が英語で刻まれた銘板があります
  • 157本の鉄管：ダムの底にしみこんだ水がダムを押し上げる力（揚圧力）を下げるため、直径1.5インチの鍛鉄管が157本、堤体の中に入れられています。見た目にはわかりませんが、明治の技術者の工夫です
  • 五本松かくれ滝：ダムが満水になって水があふれたときにだけ現れる「幻の滝」です。平成19年（2007年）に公募で名前がつけられました
  • 夜のライトアップ：夜間はライトアップされ、新神戸ロープウェーや遊歩道からその景色を眺められます

放流やイベント

布引五本松ダムは水道用のダムで、日程を決めて行う観光放流はありません。満水になって水があふれたときに「五本松かくれ滝」が現れますが、いつ見られるかは雨の量しだいで、公式に日程が発表されるものではありません。

ダムカードの配布

国土交通省がまとめている「ダムカード配布場所一覧」（令和8年1月16日現在）の兵庫県の欄には、布引五本松ダムは載っていません。今のところ、公式のダムカードの配布は確認できませんでした。→ ダムカードのもらい方

行き方とハイキングコース

布引五本松ダムへは、新神戸駅から歩いて行くのが基本です。新神戸駅から六甲山へ向かうハイキングコースが整備されていて、途中に観察所や休憩所もあります。神戸市中央区の「布引・市ヶ原を美しくする会」のマップでは、次のようなコースが紹介されています。

コース距離時間のめやす
新神戸駅 → 布引の滝 → 新神戸駅1km40分
新神戸駅 → 布引の滝 → 布引貯水池 → 新神戸駅4km90分
新神戸駅 → 布引の滝 → 布引貯水池 → 市ヶ原 → 新神戸駅6km120分

ダムを見るなら、布引貯水池を通る4kmのコース（約90分）がめやすです。山道なので、歩きやすい靴で出かけましょう。

あわせて見たい周辺のスポット

布引の滝

神戸を代表する名所で、上から雄滝（おんたき）、夫婦滝（めおとだき）、鼓ヶ滝（つつみがたき）、雌滝（めんたき）の4つの滝をまとめて「布引の滝」と呼びます。昔から多くの貴族や歌人が訪れ、『伊勢物語』などの古典にも登場します。滝の近くには、ダムと同じ明治33年に完成した取水施設「雌滝取水堰堤」があり、これも重要文化財の一つです。

みはらし展望台

神戸の市街地を一望できる展望台で、神戸空港やハーバーランドも見えます。

布引三十六歌碑と砂子橋

コース沿いには、滝にまつわる名歌36首を刻んだ歌碑があります。ハイキングルートの入口にあるレンガ積みの砂子橋（いさごばし）も、布引水源地水道施設の一つです。

神戸布引ハーブ園・新神戸ロープウェー

六甲山の中腹にあるハーブ園で、約200種、7万5千株のハーブや花が植えられています。ふもとの駅と結ぶ6人乗りのロープウェーから、神戸の景色を眺められます。

見学におすすめの季節

ハイキングコースは一年を通して歩けます。コースの近くにある徳光院は、地元のおすすめの紅葉スポットとして紹介されています。秋は紅葉と明治のダムを一緒に楽しめる季節です。雨のあとは道がすべりやすく、川も増水するので気をつけましょう。

行く前のチェックリスト

  1. 歩きやすい靴と飲み物（新神戸駅から往復約90分の山道）
  2. 地図とライト。日が短い季節は早めに出発する
  3. イノシシに出会ったら、えさをあげたり近づいたりせず、ゆっくり後ずさりする
  4. 雷や雨のときは、すぐに川から離れる
  5. ごみは持ち帰る

よくある質問

新神戸駅からどのくらい歩きますか？
新神戸駅から布引の滝を通って布引貯水池をめぐり、駅に戻るコースは約4km・約90分です。
日本で最初のコンクリートダムというのは本当ですか？
神戸市は「水道専用の重力式コンクリートダムとしては日本初」、文化庁は「我が国における重力式コンクリート造堰堤の嚆矢（始まり）」と説明しています。
ダムカードはもらえますか？
国土交通省のダムカード配布場所一覧には載っておらず、公式の配布は確認できませんでした。
五本松かくれ滝はいつ見られますか？
ダムが満水になって水があふれたときだけ現れる滝なので、決まった日はありません。
