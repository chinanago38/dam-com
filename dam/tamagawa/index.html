玉川ダムの見学ガイド

最終確認日：2026年11月25日

高さ 100.0m重力式コンクリートダム秋田県 仙北市田沢湖玉川ダム湖：宝仙湖

玉川（たまがわ）ダムは、秋田県仙北市田沢湖玉川にある、高さ100mの重力式コンクリートダムです。雄物川水系の玉川をせき止めていて、1990年（平成2年）10月に竣工式が行われ、1991年4月から国土交通省東北地方整備局の玉川ダム管理所が管理しています。

このダムの特徴は2つあります。ひとつは、高さ100m級のダムとして初めてRCD工法（固く練ったコンクリートを一般的な重機で運んで締め固める工法）を採用したこと。もうひとつは、上流の玉川温泉から流れ出す強い酸性の水と長く向き合ってきたダムであることです。ダムの湖は宝仙湖（ほうせんこ）と呼ばれ、「ダム湖百選」にも選ばれています。

高さくらべ

玉川ダムのあゆみ

  • 1971年（昭和46年）4月：湯沢工事事務所が予備調査を開始
  • 1973年（昭和48年）4月：玉川ダム調査事務所が発足
  • 1980年（昭和55年）8月：本体工事に着工。翌1981年9月にRCD工法の試験施工を始める
  • 1983年（昭和58年）9月：本体コンクリートの打設を開始。1984年6月に定礎式
  • 1986年（昭和61年）5月：本体コンクリートの打設量が100万m³に到達
  • 1989年（平成元年）10月：試験湛水を開始し、1990年4月にサーチャージ水位に到達
  • 1990年（平成2年）5月：土木学会技術賞を受賞。9月に付け替えた国道341号が全面開通し、10月に竣工式
  • 1991年（平成3年）4月：玉川ダム管理所に移行

玉川温泉の酸性水と中和処理

玉川の上流には、源泉の「大噴（おおぶけ）」からpH1.1、97℃の湯が毎分8,400リットルわき出す玉川温泉があります。この強い酸性の水が流れ込むことが、玉川の水を使ううえで長い間の課題でした。下流では、農業用水の基準とされるpH6.0〜7.5の水を確保することが求められていました。

1940年（昭和15年）には、玉川の水を田沢湖に引き込んで酸性を薄めようとしましたが、今度は田沢湖が酸性になって魚がいなくなってしまいました。1972年（昭和47年）からは秋田県が、積み上げた石灰石に酸性水をかける簡単な方法で中和を行っていました。

玉川ダムの建設とあわせて造られたのが「玉川酸性水中和処理施設」です。1991年（平成3年）4月に本運転を始め、今は直径5〜20mmの石灰石を詰めた円すい形の槽に温泉水を下から通す「粒状石灰中和方式」で、pH1.1〜1.3の水をpH3.5以上にしてから川へ流しています。使う石灰石は1日約40トンです。運転開始前のダム地点のpHは、コンクリートなどへの影響の限界とされるpH4.0を下回っていましたが、2008年（平成20年）の測定では玉川ダムでpH4.9、田沢湖でpH5.2まで改善しています。

中和処理施設の見学は、通常の見学コースとは別に玉川ダム管理所への相談が必要です。

玉川ダムの役割

  • 洪水を防ぐ：ダム地点で毎秒2,800m³と想定される洪水のうち毎秒2,600m³をため、下流へは毎秒200m³だけを流します
  • 川の流れを保つ：下流の広久内・長野・椿川の各地点で、決められた流量を下回らないように水を補給します
  • 田んぼの水：仙北平野の約10,200haの農地に水を送ります
  • 水道：秋田市の水道に、1日最大113,900m³の水を送ります
  • 工業用水：秋田湾周辺の工業地域に、1日452,500m³を送ることができます
  • 発電：ダムの真下の玉川発電所で最大23,600kWを発電します（約23,000世帯分）

見学コースと資料室

玉川ダムの見学は平日のみで、土・日・祝日の見学は行っていません。時間は9:30〜11:00と13:30〜15:00で、1人から受け付けています。

コース所要時間予約
①取水塔 → ゲートハウス30分不要
②資料室 → 取水塔 → ゲートハウス50分見学日の10日前まで
③資料室 → 取水塔 → ゲートハウス → 下段監査廊60分見学日の10日前まで
  • 予約は、管理所のホームページにある申込用紙をFAXかメールで送ります。電話での問い合わせは平日9:00〜17:00です
  • 洪水や渇水、地震、訓練のときなどは、希望の日に案内できない場合があります
  • 資料室は9:00〜17:00の開館で、ダムができるまでの経過や役割、湖のまわりの生き物を、模型・映像・標本・パネルで紹介しています。11月下旬から4月下旬までは冬期閉鎖です

2026年の放流とイベント

  • クレストゲートの試験放流（5月22日、14:00〜16:00予定）：ダムのいちばん上にあるクレストゲートは、100年に1度ほどの大きな洪水のときにしか使わない非常用の設備です。管理開始から35年で11回目となる試験放流が行われ、見学は無料で、見学した人にはダムカードが配られました。管理所は、下流公園からの眺めを勧めていました
  • 玉川ダム宝仙湖まつり（7月26日）：ダムの堤体と玉川発電所の見学、堤体への落書きコーナー、木工教室、ストーンアート、はたらく車の展示、魚の観察などが行われました

試験放流は毎年決まった日程で行われるものではありません。2027年の予定は、2026年11月25日の時点では発表されていません。ほかのダムの放流は観光放流カレンダーにまとめています。

行き方

住所秋田県仙北市田沢湖玉川字下水無92（玉川ダム管理所）
車東北自動車道の盛岡ICから国道46号・341号経由で約80分。秋田市から約90分、鹿角市から国道341号で約80分。JR田沢湖駅からは約30分です
バスJR田沢湖駅前から羽後交通バスの「急行八幡平線」に乗り、「玉川ダム」で下車。冬期は路線が「急行新玉川線」に変わります

冬に行くときの注意

  • 2026年は11月30日を最後に資料室が冬期閉鎖になり、その年のダム見学も終わります
  • 同じ日の18:00から、国道341号の新玉川付近が冬期通行規制区間になります。これにあわせて、ダム入口と下流公園の公衆トイレも12月1日から使えなくなります
  • 冬もダムカードは管理所でもらえますが、管理所は雪道での来訪に気をつけるよう呼びかけています

季節ごとの楽しみ方と周辺

  • 春：下流公園の桜が咲きます
  • 夏：管理所の写真集では、宝仙湖の水面が鏡のように景色を映す「水鏡」が紹介されています。7月には宝仙湖まつりがあります
  • 秋：ダムと宝仙湖のまわりが紅葉し、下流公園ではナナカマドが色づきます
  • 田沢湖：玉川の水が引き込まれ、酸性化と水質改善の歴史をたどってきた湖です。ダムのマスコット「ロン」と「ルン」は、田沢湖の辰子姫伝説にちなんだ龍の子どもという設定です

行く前のチェックリスト

  1. 資料室は11月下旬〜4月下旬は閉鎖。開館時間は9:00〜17:00
  2. 見学は平日のみ。資料室や監査廊も見たいなら10日前までに予約
  3. 土日にダムカードをもらうなら、管理所の玄関わきのインターホンを使う
  4. 冬は国道341号の規制とバス路線の変更を確認する
  5. 試験放流やイベントは、管理所のホームページとXで告知される

よくある質問

土日でもダムカードはもらえますか？
もらえます。配布は土・日・祝日を含む8:30〜17:00で、休日は管理所正面玄関わきのインターホンを押して受け取ります。巡回などで対応できないこともあります。
土日にダムの中を見学できますか？
玉川ダムの見学は平日のみです。予約不要の取水塔・ゲートハウスのコースも平日の案内です。
なぜ酸性の水が流れてくるのですか？
上流の玉川温泉の源泉「大噴」から、pH1.1の強い酸性の湯が毎分8,400リットルわき出しているためです。今は中和処理施設でpH3.5以上にしてから川へ流しています。
放流は見られますか？
2026年5月22日には、ふだん使わないクレストゲートの試験放流が一般に公開されました。毎年の予定ではないので、管理所の発表を確認してください。
